# Bestaff Mobile App Documentation

## 📚 Overview

This directory contains comprehensive technical documentation for the **BeStaff Mobile** project. The documentation is designed to help developers, architects, and stakeholders understand the architectural decisions, design patterns, and best practices implemented in the monorepo.

## 📂 Contents

### [ARCHITECHTURE.md](ARCHITECHTURE.md)
Complete architectural documentation covering:

- **System Overview**: High-level architecture philosophy and design principles
- **Technology Stack**: Detailed breakdown of all frameworks, libraries, and tools
- **Monorepo Architecture**: Turborepo configuration, workspace structure, and dependency graph
- **Core Packages**: In-depth documentation of all shared packages (`@bestaff/theme`, `@bestaff/ui`, `@bestaff/hooks`, `@bestaff/utils`, `@bestaff/logger`)
- **Application Architecture**: Mobile app structure, component hierarchy, and layers
- **Design System**: Theme system, design tokens, styling factories
- **State Management**: TanStack Query, React Context patterns
- **Routing & Navigation**: Expo Router 6 file-based routing
- **Build & Deployment**: Turborepo pipeline, EAS Build configurations
- **Testing Strategy**: Unit, integration, and E2E testing approaches
- **Development Workflow**: Git workflow, code review, CI/CD pipelines
- **Performance Optimizations**: Bundle size, rendering, caching strategies
- **Security Considerations**: Authentication, data protection, secure storage

## 👥 Intended Audience

- **Developers**: Understanding codebase structure, patterns, and conventions
- **Architects**: System design decisions and architectural patterns
- **Team Leads**: Onboarding new team members and technical planning
- **DevOps Engineers**: Build, deployment, and CI/CD configuration
- **Stakeholders**: Technical overview and system capabilities

## 🔄 Maintenance

This documentation should be updated when:

- Major architectural changes are implemented
- New packages or apps are added to the monorepo
- Technology stack is upgraded or replaced
- New patterns or conventions are established
- Significant refactoring occurs
